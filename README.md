# HireSync – Smart Recruitment Matching Platform

HireSync is a four-member university software engineering project for deterministic recruitment matching.

## Technology

- Angular 22 + TypeScript
- ASP.NET Core Web API / .NET 8
- SQL Server 2022 Express
- Entity Framework Core 8
- ASP.NET Core Identity + JWT
- xUnit, Vitest and Playwright
